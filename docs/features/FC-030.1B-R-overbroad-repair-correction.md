# FC-030.1B-R — Overbroad Repair Correction

The first implementation attempt in commit `8080a6f41333a1b12099bad19becca2ca1afce44` changed unrelated descriptor representation details while introducing computed-column support. Those unrelated changes are not part of the FC-030.1B-R amendment and must not become authority.

The correction restores the pre-repair FC-030.1B executable vocabulary exactly, except for the single approved computed-column delta:

```text
SqlComputedDescriptor(Definition, IsPersisted)
SqlColumnDescriptor.Computed
SqlSchemaDifferenceKind.ColumnComputedMismatch
computed-column comparison using SqlFragmentCanonicalizer
```

No change to `SqlLengthDescriptor`, index-column ordinal naming, PK/UQ convenience constructors, existing enum values, or any other descriptor semantics is authorized by FC-030.1B-R.
