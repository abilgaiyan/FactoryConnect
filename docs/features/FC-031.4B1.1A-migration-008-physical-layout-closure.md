# FC-031.4B.1.1A — Migration 008 Physical Layout Closure

Status: **CLOSED / FROZEN**

Baseline: `de487c2860d96ed16c0462d657095cb61358dc3a`

## Authority

This record closes the SQL Server physical-layout authority consumed by Migration 008. It introduces no new portable FC-031 semantics.

Decision 1 freezes the Mapping and joint Projection/E authority roots. Decision 2 freezes normalized current-signal storage and the S1 SignalType + Value physical codec. Decision 3 freezes append-only state-change and activity-period histories with independent per-kind `OutputOrdinal` sequences correlated by `ProjectionRevision + OutputOrdinal`.

## Migration 008 objects

Migration 008 owns exactly these new tables:

- `dbo.MappingCoverageAuthority`
- `dbo.MachineStateActivityAuthority`
- `dbo.MachineStateActivitySignal`
- `dbo.MachineStateChangeHistory`
- `dbo.MachineActivityPeriodHistory`

It introduces no SQL sequence, identity column, trigger, separate EvaluationAuthority table, shared history-output relation, or global cross-kind output ordinal.

All PK/FK/CHECK/index names are deterministic and repository-owned. No SQL Server-generated owned object names are permitted.

## History correlation

State-change and activity-period histories independently use:

```text
parent authority lineage
+ ProjectionRevision
+ OutputOrdinal
```

`OutputOrdinal` is independently scoped per publication and history kind. No cross-kind ordering semantics exist.

History `ProjectionRevision` is correlation data and is not foreign-keyed to the current root revision; historical rows must survive later root advancement.

## Current signals

`dbo.MachineStateActivitySignal` is a current snapshot child relation, not history. New publication replaces the complete current child set atomically with joint P/S/A/E publication. Empty signals are represented by zero child rows. Exact replay performs no mutation.

Analog and Numeric decimal payloads use CanonicalDecimalTextV1 stored as `nvarchar(64) COLLATE Latin1_General_100_BIN2`. Signal key, source, and text/enumeration payloads use `nvarchar(max) COLLATE Latin1_General_100_BIN2` without V2 companions or SQL semantic comparison authority.

## Descriptor and owned-object authority

The post-008 schema descriptor appends the five Migration 008 tables to the immutable post-007 descriptor. The current descriptor advances to post-008 while post-007 remains an explicit historical descriptor.

The owned-object recognition set adds exactly the same five tables.

No descriptor vocabulary extension is required.

## Contradiction audit

The consolidated layout preserves Decisions 1–3, S1, D6, D7, and the portable FC-031.2/FC-031.3 boundaries. In particular:

- one joint Projection/E current root remains authoritative;
- Position/EvaluatedThrough and Projection/E MachineState are each physically normalized once;
- processor identity remains StringOrderKeyV2-backed;
- policy strings and signal payload strings gain no unauthorized SQL semantic equality authority;
- current signals remain normalized snapshot children;
- both history relations remain append-only;
- history ordinals remain independent per kind and publication;
- no shared cross-kind output sequence is introduced;
- SQL Server representation choices remain provider-local.

Blocking contradiction: **NONE**.
