## Scope closed

This slice establishes the in-memory provider implementation for reading one stable current-state authority cut from the provider-owned acquisition, mapping, and state/activity authority instances established by FC-031.2E.A.

The production scope is limited to:

```text
InMemoryCurrentStateAuthorityCutProvider
InMemoryPersistenceServiceCollectionExtensions
```

The provider reads the existing authority contracts without changing their public shape and is carried as the optional `CurrentStateAuthorityCutProvider` role in `PersistenceProviderServices`.

The same provider-owned authority instances are used for acquisition/contact, mapping coverage, and evaluation/state reads. No duplicate authority store graph is introduced.

## Stable-cut algorithm

Each read uses bounded optimistic validation with no delay or backoff:

```text
maximum attempts = 3

attempt
  collect acquisition / mapping / evaluation authorities
  invoke provider-private deterministic interleaving seam
  collect acquisition / mapping / evaluation authorities again
  validate both collections
  accept only when authority identities and revisions are unchanged

three unstable attempts
  -> StableCurrentStateAuthorityCutUnavailable
```

There is no fourth attempt and no retry delay.

Authority stability is determined from the existing identity and revision authorities:

```text
acquisition
  ObservationStreamId
  AcquisitionRevision

mapping
  MappingProcessorId
  ObservationStreamId
  MappingRevision

evaluation
  StateProcessorId
  ObservationStreamId
  ProjectionRevision
```

A stable collection is returned as `StableCurrentStateAuthorityCut`; unresolved instability is represented by `StableCurrentStateAuthorityCutUnavailable`.

## Stable presence proof

The provider preserves the nullable authority-cut contract and accepts stable presence shapes that satisfy binding and lineage rules.

Focused conformance proves stable publication for:

```text
all authorities absent
partial authority cuts
complete authority cuts
```

No stronger causal-prefix presence rule is introduced by this slice.

## Binding consistency proof

Every present authority must match the requested `CurrentStateAuthorityBinding`:

```text
acquisition
  ObservationStreamId == binding.ObservationStreamId

mapping
  MappingProcessorId   == binding.MappingProcessorId
  ObservationStreamId  == binding.ObservationStreamId

evaluation
  StateProcessorId     == binding.StateProcessorId
  ObservationStreamId  == binding.ObservationStreamId
```

An incompatible authority identity makes the cut unavailable rather than publishing a contradictory stable result.

## Lineage consistency proof

Present authorities are validated against the existing acquisition-to-mapping-to-evaluation lineage.

The provider rejects contradictory cuts including:

```text
mapping.MappedEvaluationInputHighWater
  > mapping.RawConsumedThrough

mapping.RawConsumedThrough
  > acquisition.RawAcceptedThrough

mapping present while acquisition is present
  but acquisition.RawAcceptedThrough is null

evaluation.EvaluatedThrough
  > mapping.MappedEvaluationInputHighWater

evaluation present with mapping present
  but mapping.MappedEvaluationInputHighWater is null
```

These checks prevent publication of a stable revision tuple whose represented processing lineage is impossible.

## Race and instability proof

A provider-private deterministic interleaving seam permits focused tests to mutate underlying authority state between the first and second collections of an attempt.

The seam is internal implementation/test support only and does not alter the public current-state contract.

Focused conformance proves:

```text
stable first attempt succeeds
first-attempt instability retries and may succeed
three consecutive unstable attempts return unavailable
retry bound is exactly three attempts
```

The bounded attempt proof observes exactly six acquisition reads and three interleaving opportunities for the fully unstable path.

## Cancellation proof

Cancellation is propagated and is never converted into authority unavailability.

Focused conformance proves cancellation before the read and cancellation introduced between the two collections of an attempt.
