# FC-030.2A — Migration 005 Owned Object Names

## Status

**CLOSED / FROZEN.**

This document freezes the deterministic names and backing-index types for every schema object introduced by `005_OperationalMetricReportingPersistence.sql`.

It does not create migration 005. It is authority consumed by FC-030.2B.

No owned PK/UQ/FK/CHECK/index name may be auto-generated by SQL Server.

  AND ShiftEndsAtUtc > ShiftStartsAtUtc
