## 3. Frozen authority model

The production authority topology is frozen as:

```text
mapped observations
    ↓
MappedObservationProcessingRuntime
    ↓
IMachineStateActivityCursorReader
    ↓
JointMachineStateActivityCursorReader
    ↓
InMemoryMachineStateActivityAuthorityStore
    ↑
JointAuthorityMachineStateActivityProcessor
    ↓
atomic P / S / A / E publication
```

Where the coherent authority tuple is:

```text
P = MachineStateActivityProjection
S = durable machine-state-change history
A = durable machine-activity-period history
E = EvaluationAuthority replay identity
```

The same composition-owned `InMemoryMachineStateActivityAuthorityStore` is the underlying authority for:

- state/activity publication;
- mapped-runtime cursor reads;
- evaluation-authority recovery state; and
- downstream production-context activity-history reads.

No independent writable current-state checkpoint or parallel state/activity owner is introduced.

## 4. Frozen coherence invariants

Established continuation requires projection and evaluation authority to agree on:

```text
processor identity
stream identity
projection position == evaluated-through position
projection state == evaluation-authority machine state
```

The replay identity additionally preserves:

```text
last-consumed acquisition instance
continuity-policy reference
```

A projection without matching evaluation authority, or evaluation authority without matching projection, is not implicitly adopted.

No legacy projection bootstrap or inferred migration rule is frozen by this slice.

## 5. Frozen continuity semantics

Mapped observations are incorporated in strictly increasing durable-position order.

For every incorporated observation, instance-boundary classification occurs before applying the mapped signal.

Same-instance continuation retains the existing evaluator context.

The frozen production continuity policy is:

```text
Identity    continuity/preserve
Version     1.0
Mode        Preserve
```

Under Preserve, acquisition-instance transition retains:

```text
Signals
State
ActiveState
ActiveStartedAt
```

The next observation is evaluated against that retained context, and `LastConsumedInstanceId` advances to the incorporated observation instance.

Reset semantics remain part of the portable continuity contract, but production Edge composition for FC-031.2D selects the canonical Preserve policy only. This slice introduces no production policy-selection surface.

## 6. Frozen atomic publication and replay semantics

State/activity mutation is frozen around coherent joint publication rather than independent projection and derived-output commits.

A successful publication advances the coherent authority state together.

The conformance proof covers:

- publication atomicity;
- projection/evaluation revision expectations;
- competing compare-and-swap behavior;
- pre-commit failure and cancellation atomicity;
- lost-acknowledgement recovery;
- replay without duplicate committed-prefix work;
- restart cursor recovery from joint projection position; and
- forward-only processing after recovery.

Lost acknowledgement does not authorize revision churn when no newer mapped input exists.

When newer input exists after an ambiguously acknowledged committed publication, only the forward suffix is processed.



Compatibility constructors and historical tests may continue to exercise legacy components where explicitly intended, but they do not restore legacy authority ownership.
