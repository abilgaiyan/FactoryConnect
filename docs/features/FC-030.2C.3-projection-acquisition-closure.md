# 1. Governing authority

FC-030.2C.1 freezes:

> **Logical processor independence is required. Zero transient physical SQL Server blocking between distinct processors is not required. Bounded incidental key-range blocking is permitted, provided correctness, ownership, atomicity, checkpoint independence, rollback, and retry semantics remain processor-safe.**

The DML authorization boundary remains:

> **Projection/manifest/evidence DML is authorized only after the implementation has acquired and validated all required projection, manifest, and evidence locks in the frozen order within the same transaction.**

No architecture decision is reopened by this closure.

# 9. Closure decision

FC-030.2C.3 is **CLOSED / FROZEN**.

The frozen result is:

> **Within the existing SQL Server Serializable publication transaction, after processor and checkpoint acquisition, C.3 acquires the complete projection processor prefix through `UQ_OperationalMetricProjection_LogicalHash` using `UPDLOCK + HOLDLOCK`, validates the complete current projection identity/state authority, acquires missing incoming identities in deterministic hash order, and returns a preparation-only mutation plan. Bounded incidental cross-processor key-range blocking is permitted under the amended C.1 authority and is directly evidenced by a live `LCK_M_*` wait whose waiting KEY lock resolves to `UQ_OperationalMetricProjection_LogicalHash`; the blocked distinct-processor writer completes after the owning transaction releases. C.3 performs no projection, manifest, evidence, or checkpoint DML.**

The next active implementation boundary is FC-030.2C.4.
