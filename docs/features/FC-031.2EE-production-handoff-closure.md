## Purpose

FC-031.2E.E closes the production-side handoff from the state/activity ownership graph established by FC-031.2E.D to the existing portable production activity-history consumer boundary.

The slice does not widen `IMachineStateActivityAuthorityStore`, add a persistence-provider activity-reader capability, introduce SQL current-state authority, or create a new public activity-history contract. The existing portable production consumer boundary remains `IProductionContextActivityReader`.

The closed topology is:

```text
ObservationAuthorityStoreGraph
        │ existing 2E.D ownership selection
        ↓
ProductionActivityAssociation
        │
        ├── combined composition
        │      ↓
        │   2E.D-selected state/activity store
        │
        └── production-only composition
               ↓
            association-owned InMemory fallback
        ↓
JointProductionContextActivityReader
        ↓
IProductionContextActivityReader
        ↓
production processing
```

## Frozen Decisions

### Decision 1 — Combined-Composition Graph Convergence

In combined observation + production composition, the production activity reader is tied to the single state/activity graph selected by FC-031.2E.D.

A separately resolved concrete store, independently manufactured fallback, independently registered reader, or matching concrete type is not sufficient ownership evidence.

```text
same concrete type != same graph
same DI interface != same graph
```

The association between state/activity ownership and production activity-history reading must be explicit inside the completed service-provider graph.

### Decision 2 — Production-Only Compatibility and Association Boundary

Production metric-input processing without observation processing retains the existing standalone InMemory activity-history fallback.

Registration order, descriptor replacement, `TryAddSingleton`, or ordinary single-service resolution is not production-reader ownership authority.

The guarantee is scoped to one completed `IServiceProvider` graph. FC-031.2E.E does not coordinate ownership across separately constructed service providers.

### Decision 3 — Future Provider Participation

A future non-InMemory provider may participate in combined observation/production composition only when the relationship between its selected state/activity graph and its `IProductionContextActivityReader` is explicitly represented.

Independent resolution of those two services is not sufficient evidence that they share activity history.

If a selected non-InMemory state/activity graph has no explicitly associated production activity reader, production composition must fail closed rather than silently consume an unrelated reader.

The future-provider binding extension is reserved for separate review. FC-031.2E.E does not add a provider capability bit, provider-services role, SQL authority implementation, or public contract for that future case.

### Decision 4 — Shared Edge Production Activity Association

Within one completed Edge service-provider graph, production activity-history ownership is represented by exactly one production-owned association.

When observation processing participates, the association derives its state/activity store through the internal Edge projection of the existing FC-031.2E.D `ObservationAuthorityStoreGraph`. It does not repeat provider/fallback selection, independently manufacture authority ownership, resolve `IMachineStateActivityAuthorityStore` to infer ownership, or use concrete type identity as ownership authority.

When observation processing is absent, the association owns exactly one compatible InMemory state/activity fallback.

The association constructs exactly one `JointProductionContextActivityReader` over the associated store. That same reader is the authoritative `IProductionContextActivityReader` projection consumed by production processing.

Registration order before provider construction does not determine state/history ownership. If another `IProductionContextActivityReader` registration displaces FactoryConnect's authoritative projection in the completed registration graph, association materialization fails closed rather than silently exposing or consuming the competing reader.
