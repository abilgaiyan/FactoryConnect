# FC-031.2D.5B — Production Edge Cutover

Status: CLOSED / FROZEN

## Scope

FC-031.2D.5B cuts the production Edge composition from the legacy state/activity projection path to the already-frozen joint machine-state/activity authority.

Implemented scope:

- production mapped runtime cursor authority through `IMachineStateActivityCursorReader`;
- production state/activity mutation through `JointAuthorityMachineStateActivityProcessor`;
- one composition-owned `InMemoryMachineStateActivityAuthorityStore` as the underlying joint authority state;
- production-context activity history through `JointProductionContextActivityReader` over that same concrete joint store;
- canonical production continuity policy registration using `continuity/preserve @ 1.0`;
- focused Edge composition and existing integration conformance proof.

Explicitly excluded:

- FC-031.2D.5C runtime-recovery conformance, including the F-01..F-06 matrix;
- FC-031.2D.5D whole composition/downstream compatibility closure;
- SQL current-state authority;
- FC-031.2E+.

## Frozen production composition semantics

### Joint authority ownership

`AddFactoryConnectObservationProcessing(...)` owns the FC-031.2D.5B joint composition boundary.

Competing registrations for the following services are removed before the production joint graph is installed:

```text
InMemoryMachineStateActivityAuthorityStore
IMachineStateActivityAuthorityStore
IMachineStateActivityCursorReader
CurrentStateContinuityPolicy
JointAuthorityMachineStateActivityProcessor
IMappedMachineObservationProcessor
```

The resulting authority interface resolves to the composition-owned concrete singleton.

The mapped processor resolves to `JointAuthorityMachineStateActivityProcessor` and no competing production processor registration is silently retained.

### Mapped-runtime cursor cutover

`MappedObservationProcessingRuntime` consumes the portable read-only cursor seam:

```text
IMachineStateActivityCursorReader
```

Production Edge composition supplies `JointMachineStateActivityCursorReader` backed by the same concrete joint authority store used by the processor.

The mapped read cursor therefore derives from:

```text
joint MachineStateActivityProjection.Position
```

No new mapped-processing checkpoint or independent writable state is introduced.

The compatibility constructor accepting `IMachineStateActivityProjectionStore` remains available for legacy/direct component-test construction only. It is not used by the production 2D.5B composition.

### Production activity-history cutover

`AddFactoryConnectProductionMetricInputs(...)` composes `JointProductionContextActivityReader` over `InMemoryMachineStateActivityAuthorityStore`.

The activity history consumed by production-context processing therefore comes from the cumulative activity-period history atomically published by the joint authority owner.

The legacy projection-backed activity reader is not the production source after this cutover.

### Canonical continuity policy

The production composition registers the frozen canonical immutable policy as the `CurrentStateContinuityPolicy` singleton:

```text
Identity    continuity/preserve
Version     1.0
Mode        Preserve
```

The joint processor resolves that registered singleton rather than constructing or selecting continuity policy independently.

No production Reset configuration or continuity-policy selection surface is introduced in 2D.5B.

## Review repairs

Two blocking composition findings were raised after the initial cutover implementation and are closed in the reviewed HEAD.

### P1 — competing registrations could split the joint authority graph

Initial risk:

```text
processor + cursor -> pre-existing IMachineStateActivityAuthorityStore
activity history    -> concrete InMemoryMachineStateActivityAuthorityStore
```

A pre-existing `IMappedMachineObservationProcessor` could also prevent the required production substitution.

Repair:

- competing joint-store/interface/cursor/processor registrations are removed;
- one concrete `InMemoryMachineStateActivityAuthorityStore` is registered;
- authority interface, cursor reader, and joint processor resolve from that concrete singleton;
- the required `IMappedMachineObservationProcessor` registration is installed deterministically.

Focused composition proof deliberately pre-registers competing authority and processor bindings and verifies they are replaced.

P1 status: CLOSED.

### P2 — canonical continuity policy was used inline but not composed

Initial risk:

`CanonicalCurrentStateContinuityPolicies.Preserve` was passed directly to the processor factory without being registered as the composition-owned production policy.

Repair:

- the canonical Preserve instance is registered as `CurrentStateContinuityPolicy`;
- `JointAuthorityMachineStateActivityProcessor` resolves that registered policy;
- focused proof verifies instance identity and the frozen identity/version/mode.

P2 status: CLOSED.
