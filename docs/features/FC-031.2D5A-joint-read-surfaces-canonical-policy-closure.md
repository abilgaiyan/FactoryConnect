## Frozen read-boundary semantics

### Joint cursor seam

The cursor read contract is portable and consumable from Core without a Core →
Infrastructure dependency.

```text
FactoryConnect.Abstractions
    IMachineStateActivityCursorReader

FactoryConnect.Infrastructure
    JointMachineStateActivityCursorReader
        implements IMachineStateActivityCursorReader
```

The cursor value derives only from:

```text
MachineStateActivityAuthoritySnapshot
    .Projection
    .Position
```

An absent authority lineage produces a null cursor.

No independent checkpoint or mutation surface is introduced.

### Joint activity-history adapter

`JointProductionContextActivityReader` reads cumulative activity-period history
from the same `InMemoryMachineStateActivityAuthorityStore` that owns the joint
state/activity authority.

The read-only adapter preserves the inherited production-context activity-reader
semantics:

- stream-specific history;
- strict `Position > afterPosition` filtering;
- ascending `Position` ordering;
- `batchSize` limiting;
- argument validation;
- cancellation.

No second activity-history state or writable authority is introduced.

### Canonical continuity policy

The canonical composition-owned Preserve policy is frozen as:

```text
Identity    continuity/preserve
Version     1.0
Mode        Preserve
```

The policy is exposed as one stable immutable singleton-compatible instance.

Production registration and policy substitution remain deferred to
FC-031.2D.5B.

## Review repairs

Two review findings were raised during 2D.5A review and are closed in the
reviewed implementation.

### P1 — Cursor layering

Original issue:

```text
JointMachineStateActivityCursorReader
    located only in Infrastructure

MappedObservationProcessingRuntime
    located in Core
```

That shape was not consumable by Core without violating the existing project
layering.

Repair:

```text

    moved to / defined in FactoryConnect.Abstractions

JointMachineStateActivityCursorReader
    implements the portable abstraction in Infrastructure
```

Result:

- Core can consume the read-only cursor contract;
- no Core → Infrastructure dependency is required;
- no circular project reference is introduced.

P1 status: CLOSED.


P2 status: CLOSED.
