# FC-030.1B-R — Computed Column Descriptor Contract Amendment

## Status

**CLOSED / FROZEN**

FC-030.1B-R is complete. The computed-column descriptor vocabulary, SQL Server metadata projection, comparison semantics, real-SQL proofs, and regression gates are frozen by this document and the recorded final evidence.

FC-030.2B may now resume against the already-frozen FC-030.2A authority. This closure does not itself implement or alter migration 005 or the post-005 `CurrentSchemaDescriptor`.

## Classification

Repository history confirms that computed-column semantics were absent from both the original FC-030.1B executable descriptor vocabulary and the governing FC-030.1 contract. This work is therefore a narrow contract amendment, not merely an implementation-conformance repair.

The original structural-vocabulary commit `8a18113d752822d37728cf5e68ad2ead8c3b9218` ended `SqlColumnDescriptor` at `Identity` and introduced no computed/default member. The governing FC-030.1 document cataloged columns, types, length/precision/scale, nullability, keys, checks, indexes, and other explicitly cataloged artifacts, but did not separately freeze computed/default column descriptors.

This amendment is required because FC-030.2A subsequently froze `OperationalMetricProjection.MachineOrderKey` as an exact `COMPUTED PERSISTED` column. Without computed-column metadata, an ordinary `binary(16)` substitution could be misclassified as compatible.

## Frozen amendment vocabulary

```csharp
internal sealed record SqlComputedDescriptor(
    string Definition,
    bool IsPersisted);

internal sealed record SqlColumnDescriptor(
    // existing FC-030.1B members unchanged
    string Name,
    string SqlType,
    SqlLengthDescriptor? MaxLength,
    byte? Precision,
    byte? Scale,
    bool IsNullable,
    string? Collation,
    SqlIdentityDescriptor? Identity,
    SqlComputedDescriptor? Computed);
```

`Computed = null` means an ordinary non-computed column.

## Metadata authority

The SQL Server metadata reader obtains computed-column state from `sys.computed_columns` for each owned column:

```text
definition
is_persisted
```

Ordinary columns project `Computed = null`.

The reader does not infer computed semantics from type, nullability, indexes, or column naming.

`SqlComputedDescriptor.Definition` retains the SQL Server catalog expression text verbatim when projected from live SQL Server metadata. SQL Server may render additional executable parentheses or identifier formatting; the reader does not rewrite that catalog text.

## Definition comparison

`SqlComputedDescriptor.Definition` stores the SQL Server/repository expression text accepted by descriptor construction. The property name deliberately does not claim that the stored text has already been canonicalized.

Comparison uses the existing frozen `SqlFragmentCanonicalizer` policy already used by FC-030.1B for CHECK and filtered-index definition comparison.

No semantic SQL parsing, expression rewriting, commutative normalization, ad-hoc whitespace normalization, removal of executable parentheses, identifier rewriting, or other broad SQL-expression normalization is introduced by this amendment.

Equivalent lexical formatting/comments accepted by `SqlFragmentCanonicalizer` compare equal. Expressions that remain distinct after that frozen canonicalization compare unequal.

## Frozen incompatibility matrix

```text
Expected computed, actual ordinary       -> incompatible
Expected ordinary, actual computed       -> incompatible
Expected persisted, actual non-persisted -> incompatible
Expression mismatch                      -> incompatible
```

For the FC-030.2A `MachineOrderKey` authority, real-SQL proof also demonstrates that an ordinary `binary(16)` stored-column substitution is rejected.
