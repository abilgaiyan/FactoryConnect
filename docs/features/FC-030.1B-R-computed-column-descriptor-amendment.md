# FC-030.1B-R — Computed Column Descriptor Contract Amendment

## Status

**REQUIRED PREREQUISITE / ACTIVE**

FC-030.2B remains blocked until this amendment is implemented, proven against real SQL Server, and frozen.

## Classification

Repository history confirms that computed-column semantics were absent from both the original FC-030.1B executable descriptor vocabulary and the governing FC-030.1 contract. This work is therefore a narrow contract amendment, not merely an implementation-conformance repair.

The original structural-vocabulary commit `8a18113d752822d37728cf5e68ad2ead8c3b9218` ended `SqlColumnDescriptor` at `Identity` and introduced no computed/default member. The governing FC-030.1 document cataloged columns, types, length/precision/scale, nullability, keys, checks, indexes, and other explicitly cataloged artifacts, but did not separately freeze computed/default column descriptors.

This amendment is required because FC-030.2A subsequently froze `OperationalMetricProjection.MachineOrderKey` as an exact `COMPUTED PERSISTED` column. Without computed-column metadata, an ordinary `binary(16)` substitution could be misclassified as compatible.

## Frozen amendment vocabulary

```csharp
internal sealed record SqlComputedDescriptor(
    string Definition,
    bool IsPersisted);

internal sealed record SqlColumnDescriptor(
    // existing FC-030.1B members unchanged
    string Name,
    string SqlType,
    SqlLengthDescriptor? MaxLength,
    byte? Precision,
    byte? Scale,
    bool IsNullable,
    string? Collation,
    SqlIdentityDescriptor? Identity,
    SqlComputedDescriptor? Computed);
```

`Computed = null` means an ordinary non-computed column.

## Metadata authority

The SQL Server metadata reader must obtain computed-column state from `sys.computed_columns` for each owned column:

```text
definition
is_persisted
```

Ordinary columns must project `Computed = null`.

The reader must not infer computed semantics from type, nullability, indexes, or column naming.

## Definition comparison

`SqlComputedDescriptor.Definition` stores the SQL Server/repository expression text accepted by descriptor construction. The property name deliberately does not claim that the stored text has already been canonicalized.

Comparison uses the existing frozen `SqlFragmentCanonicalizer` policy already used by FC-030.1B for CHECK and filtered-index definition comparison.

No semantic SQL parsing, expression rewriting, commutative normalization, ad-hoc whitespace normalization, or other broad SQL-expression normalization is introduced by this amendment.

Equivalent lexical formatting/comments accepted by `SqlFragmentCanonicalizer` compare equal. Expressions that remain distinct after that frozen canonicalization compare unequal.

## Required incompatibility matrix

```text
Expected computed, actual ordinary       -> incompatible
Expected ordinary, actual computed       -> incompatible
Expected persisted, actual non-persisted -> incompatible
Expression mismatch                      -> incompatible
```

For the FC-030.2A `MachineOrderKey` authority, real-SQL proof must also demonstrate that an ordinary `binary(16)` stored-column substitution is rejected.

## Scope boundary

This amendment changes only:

```text
SqlComputedDescriptor
SqlColumnDescriptor.Computed
sys.computed_columns metadata projection
computed-state structural comparison
computed descriptor/unit coverage
real-SQL computed drift proofs
existing schema-classification/runtime-compatibility regression proof
```

This amendment does not change:

```text
migrations 001..004
LegacyPost004SchemaDescriptor structure
migration ledger semantics
migration locking/transaction semantics
runtime startup semantics
FC-030.2A physical authority
migration 005
post-005 CurrentSchemaDescriptor contents
default-constraint vocabulary
```

Defaults remain deferred unless separately amended by architecture review.

## Closure gate

FC-030.1B-R may be frozen only after:

```text
1. descriptor vocabulary implemented exactly as above
2. metadata reader projects definition + is_persisted from sys.computed_columns
3. comparator proves both computed/ordinary drift directions
4. comparator proves persistence-state drift
5. comparator proves expression drift using existing lexical canonicalization only
6. real-SQL incompatibility proofs pass
7. existing unledgered classification matrix passes
8. existing runtime compatibility matrix passes
9. FC-030.2B remains untouched throughout the prerequisite
```

Only after this gate closes may FC-030.2B resume against the already-frozen FC-030.2A authority.
